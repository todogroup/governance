# OSPO for Agents Working Group

## About

This working group develops comprehensive guidance, case studies, patterns, and reference materials to help organizations implement effective Open Source Program Office (OSPO) practices for managing AI agents and agent-based systems.

- **Charter**: [OSPO for Agents Charter](ospo-for-agents-charter.md)

- **GitHub Discussions**: [OSPOlogy Discussions](https://github.com/todogroup/ospology/discussions)

### Contributing

We welcome contributions in the form of:
- **Case Studies**: Share your organization's experience with AI agent governance
- **Patterns**: Document governance and architectural patterns you've discovered
- **Documentation**: Help write guidance and best practices
- **Feedback**: Review and provide input on draft materials
- **Expertise**: Share domain knowledge on compliance, security, or organizational readiness

See [CONTRIBUTING.md](./CONTRIBUTING.md) for detailed guidelines.
